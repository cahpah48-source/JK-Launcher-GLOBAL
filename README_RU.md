# JK Launcher GLOBAL 1.1.4 — исходный проект

Это обновлённая основа интерфейса Electron с навигацией, выбором версии, RAM и зелёной темой. Версия проекта повышена до **1.1.4**.

## Важно: что работает сейчас
- Интерфейс главной страницы, вкладок, выбора версии и ползунков памяти.
- Безопасная базовая конфигурация Electron: `contextIsolation`, отключённый `nodeIntegration`, sandbox и запрет всплывающих окон.
- CI-конфигурация сборки Windows x64 и ARM64.

## Что ещё НЕ реализовано
Microsoft OAuth/Xbox/Minecraft Services и проверка владения игрой; загрузка и запуск Minecraft; установка Java; установка Forge/Fabric/NeoForge; интеграция Modrinth/CurseForge; импорт профилей; автообновление; подпись установщика; поддержка и политика конфиденциальности. Эти функции нельзя честно считать готовыми в этой сборке. Пароль Microsoft не вводить в приложение.

Локальный профиль в интерфейсе не обходит проверку владения и не обещает запуск официальных серверов.

## Запуск
Требуется Node.js 22+. Выполнить `npm install`, затем `npm start`. Проверка синтаксиса: `npm run check`.

## Сборка Windows
GitHub Actions собирает NSIS и portable варианты для x64 и ARM64. Для реального выпуска нужно проверить артефакты на соответствующих Windows-системах. Кодовая подпись требует сертификата и не включена автоматически.
